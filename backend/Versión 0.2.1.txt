🟢 app/models/area.py
import uuid

from sqlalchemy import String
from sqlalchemy import Boolean
from sqlalchemy.dialects.postgresql import UUID
from sqlalchemy.orm import Mapped
from sqlalchemy.orm import mapped_column

from app.database.base import Base


class Area(Base):

    __tablename__ = "areas"

    id: Mapped[uuid.UUID] = mapped_column(
        UUID(as_uuid=True),
        primary_key=True,
        default=uuid.uuid4
    )

    name: Mapped[str] = mapped_column(
        String(100),
        unique=True,
        nullable=False
    )

    active: Mapped[bool] = mapped_column(
        Boolean,
        default=True
    )

En la siguiente entrega implementaré:

Modificación del modelo Finding para usar relaciones (ForeignKey) con Area, Classification y Status.

Endpoints CRUD para administrar los catálogos (/areas, /classifications, /statuses).

💡 Recomendación técnica

A partir de esta versión también incorporaremos Alembic para manejar migraciones de la base de datos. Hasta ahora hemos creado tablas automáticamente con create_all(), lo cual fue útil para arrancar el proyecto, pero para un sistema que seguirá creciendo (Hallazgos, CAPA, Dashboard, Auditorías, KPI, etc.) las migraciones versionadas serán mucho más seguras y profesionales.
